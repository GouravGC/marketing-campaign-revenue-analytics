# Marketing Campaign & Revenue Analytics Engineering Pipeline

## Project Overview

This project builds an end-to-end analytics pipeline that processes marketing campaign, advertising spend, conversion, and revenue data to generate reliable business insights.

## Business Objectives

- Analyze marketing spend and revenue.
- Compare campaign and channel performance.
- Calculate Cost Per Acquisition (CPA) and Return on Ad Spend (ROAS).
- Identify missing data, duplicate records, and data-quality issues.
- Build reliable analytical datasets and automated validation.
- Create an interactive Power BI dashboard.
- Reconcile analytical results using Microsoft Excel.

## Technology Stack

- Python
- SQL
- REST APIs
- Google Cloud Platform (GCP)
- BigQuery
- Power BI
- Microsoft Excel
- Git and GitHub
- pytest
- GitHub Actions

## Project Workflow

Data Sources → Python Ingestion → Data Cleaning → Data Validation → BigQuery → SQL Transformations → Analytics Tables → Excel Reconciliation → Power BI Dashboard
